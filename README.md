
# PDA–CAPWAP Machine Learning Prediction Dashboard

## Project Overview

This project develops a machine learning-based dashboard for analyzing Pile Driving Analyzer (PDA) testing data and predicting two engineering parameters:

- **DMX (mm):** Maximum pile displacement
- **Qu CAPWAP (Ton):** Pile bearing capacity reported from CAPWAP analysis

The project combines predictive modeling, engineering data analysis, model interpretation, and interactive visualization.

## Project Objectives

- Develop machine learning models for predicting DMX and Qu CAPWAP.
- Analyze relationships between pile characteristics and testing parameters.
- Evaluate predictive performance using project-based cross-validation.
- Provide an interactive dashboard for exploring model predictions.
- Explain individual predictions using SHAP.

## Dataset

The project uses an engineering dataset containing 321 PDA testing records.

Input parameters include:
- Pile type
- Pile length
- Pile dimension
- Hammer type
- Hammer weight
- Drop height

Target variables:
- DMX (mm)
- Qu CAPWAP (Ton)

The original dataset is not included in this public repository.

## Machine Learning Methodology

### 1. Data Preprocessing
- Data cleaning and validation
- Feature engineering
- Numerical feature scaling
- Categorical feature encoding

### 2. Predictive Modeling
Two independent Random Forest regression models are developed for:
- DMX prediction
- Qu CAPWAP prediction

### 3. Model Evaluation
Model performance is evaluated using five-fold GroupKFold cross-validation, with projects separated across training and testing folds.

Evaluation metrics:
- R² (Coefficient of Determination)
- RMSE (Root Mean Squared Error)
- MAE (Mean Absolute Error)

### 4. Model Interpretability
- Permutation Feature Importance
- SHAP explanations
- Input coverage checks

## Interactive Dashboard

The project includes a Gradio-based dashboard that allows users to:

- Select the prediction target (DMX or Qu)
- Enter pile characteristics
- Enter hammer testing parameters
- Generate machine learning predictions
- View SHAP explanations
- Check whether input values fall within training-data ranges

The dashboard is implemented in the Google Colab notebook.

## How to Run

1. Open `PDA_DMX_Qu_CAPWAP.ipynb` in Google Colab.
2. Install the required Python packages.
3. Upload the authorized Excel dataset.
4. Run the data preprocessing cells.
5. Train and evaluate the prediction models.
6. Launch the Gradio dashboard.

Note: The dataset is required to reproduce the model training and predictions.

## Limitations

- Predictions are based on the available training dataset.
- Qu values retain the original source unit, Ton, which requires engineering interpretation.
- Model outputs are exploratory and should not replace professional engineering assessments.
- The Gradio sharing link generated by Colab is temporary.
- The notebook does not yet include a complete standalone deployment application.
